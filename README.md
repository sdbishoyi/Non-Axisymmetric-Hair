# Numerical Evidence for Non-Axisymmetric Gravitational “Hair” for Extremal Kerr Black Hole Spacetimes with Hyperboloidal Foliations


# Description of folders:

## Data folders

* new_data_l2m2
* data_l3m2
* data_l3m3
* old_data_l2m2
* data_06172024

**Remark-1**: I think only old_data_l2m2 was used for analysis. 
Quality of results was worse for **lower resolution in time** data i.e. new_data.


## Analysis folders:

* analysis_l2m2 : analysis for the spherical harmonic modes $\ell=2, m=2$
* analysis_l3m2 : analysis for the spherical harmonic modes $\ell=3, m=2$
* analysis_l3m3 : analysis for the spherical harmonic modes $\ell=3, m=3$

**Remark-**: l3m3 data quality was insufficient for its analysis to be 
included in paper.


# Getting Started

* Read ```instructions.md``` as provided inside each of the analysis folders listed above. 
* Start with l2m2 folder since l3m2 is almost identical in methodology. Read **instructions.md**.
* There are matlab files such as "bbscalar_vs_t.m" which can be directly run.
* Notebooks provide details about the experiments carried out.
